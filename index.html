Задача

Задачи разрознены — Excel, мессенджеры, стикеры. Потерянные дедлайны, отсутствие видимости загрузки команды.

Контроль финансов

MVP React TypeScript Tailwind CSS Chart.js
Задача

Человек хочет контролировать расходы, но не хочет сложные приложения с регистрацией и облаком. Нужен простой инструмент для учёта трат и доходов.

Решение

Веб-приложение с добавлением расходов/доходов, статистикой по категориям, балансом, планированием крупных покупок и архивом. Данные хранятся в браузере — без регистрации и серверов.

Результат

Приложение помогает видеть, сколько тратишь на базовые нужды vs «nice to have», планировать крупные расходы и контролировать баланс. Доступно на компьютере и телефоне.

Рационика — Интеллектуальный калькулятор рационов

Calculator Chatbot Python FastAPI Telegram Bot Vite
Задача

Клиентам службы доставки готовой еды сложно рассчитать стоимость рационов для разных программ (Classic, Balance, Vegan) и групп клиентов (взрослые/дети).

Решение

Калькулятор автоматически формирует меню на нужное количество дней, считает стоимость по программам, учитывает детские порции и скидки.

Результат

Менеджер получает точный расчёт за 30 секунд вместо ручного подсчёта. Заказы сохраняются и доступны в админ-панели.
